WHERE filters individual rows before any grouping happens and cannot reference aggregate functions like COUNT or SUM directly. HAVING filters groups after GROUP BY has been applied, and is specifically used to filter based on aggregate results — for example, "show only departments with more than 5 employees."

INNER JOIN returns only rows that have matching values in both joined tables — non-matching rows from either side are excluded. LEFT JOIN returns all rows from the left (first) table, plus matching rows from the right table, filling in NULL for columns where no match exists. This makes LEFT JOIN essential when you need to keep "no match" cases visible, like finding customers with zero orders.
