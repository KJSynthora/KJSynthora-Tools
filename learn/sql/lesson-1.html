SQL Basics: SELECT, WHERE, ORDER BY

⏱ 45 min read 📊 Beginner 🗄️ SQL Course 📅 Updated 2026
Share: WhatsApp Twitter / X LinkedIn

SQL (Structured Query Language) is how we talk to databases. Whether you're a data analyst, backend developer, or just curious about data — SQL lets you ask questions and get instant answers. This lesson covers the four most fundamental building blocks: SELECT, WHERE, ORDER BY, and LIMIT.

1. What is a Database and a Table?

A database is an organized collection of data. Inside a database, data is stored in tables — think of a table exactly like a spreadsheet, with rows (records) and columns (fields).

For every example in this lesson, we'll use an employees table:

3Sneha KumarEngineering92000Hyderabad

2. The SELECT Statement

The SELECT statement retrieves data from a table. The most basic form selects all columns using the * wildcard:

SQLSelect all columns
1
SELECT * FROM employees;

This returns every column and every row from the employees table. Usually you only need specific columns:

SQLSelect specific columns
1 2
SELECT name, department, salary FROM employees;

This returns only the name, department, and salary columns for all 5 employees.

💡 Tip: Always select only the columns you need. Using SELECT * on large tables with hundreds of columns wastes memory and slows down queries significantly.

3. Filtering with WHERE

The WHERE clause filters rows based on a condition — only rows where the condition is true are returned.

SQLFilter by department
1 2 3
SELECT name, salary FROM employees WHERE department = 'Engineering';
Result — 2 rows returned
namesalary
Priya Sharma85000
Sneha Kumar92000

You can also use comparison operators with numbers:

SQLFilter by salary
1 2 3
SELECT name, salary FROM employees WHERE salary > 70000;

Common Comparison Operators

  • = — equal to
  • != or <> — not equal to
  • > — greater than
  • < — less than
  • >= — greater than or equal to
  • <= — less than or equal to
📌 Note: Text values in SQL must be wrapped in single quotes, like 'Engineering'. Numbers do not need quotes. Double quotes work in some databases but single quotes are the SQL standard.

4. Sorting with ORDER BY

The ORDER BY clause sorts your results. Default order is ascending (A→Z, smallest→largest). Add DESC for descending order.

SQLSort by salary — highest first
1 2 3
SELECT name, salary FROM employees ORDER BY salary DESC;
Result — sorted highest salary first
namesalary
Sneha Kumar92000
Priya Sharma85000
Anjali Rao71000
Arjun Reddy62000
Vikram Singh58000

You can sort by multiple columns:

SQLMulti-column sort
1 2 3
SELECT name, department, salary FROM employees ORDER BY department ASC, salary DESC;

This sorts alphabetically by department first, then within each department by salary from highest to lowest.

5. Limiting Results with LIMIT

The LIMIT clause restricts how many rows are returned — perfect for "top N" queries like finding the 3 highest-paid employees.

SQLTop 3 highest paid
1 2 3 4
SELECT name, salary FROM employees ORDER BY salary DESC LIMIT 3;
⚠️ Common Mistake: The order of clauses always matters. The correct sequence is:
SELECT → FROM → WHERE → ORDER BY → LIMIT
Writing them in any other order causes a syntax error.

6. Combining Everything

Here's a complete query using all four clauses together — find the top 2 highest-paid employees in Engineering:

SQLFull query — all clauses
1 2 3 4 5
SELECT name, department, salary FROM employees WHERE department = 'Engineering' ORDER BY salary DESC LIMIT 2;
Result — Top 2 Engineering employees by salary
namedepartmentsalary
Sneha KumarEngineering92000
Priya SharmaEngineering85000

✅ Lesson Summary

  • SELECT — choose which columns to retrieve
  • FROM — specify the table to query
  • WHERE — filter rows based on a condition
  • ORDER BY — sort results (ASC default, DESC for reverse)
  • LIMIT — restrict the number of returned rows
  • Clause order matters: SELECT → FROM → WHERE → ORDER BY → LIMIT
