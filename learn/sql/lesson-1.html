SQL Basics: SELECT, WHERE, ORDER BY

⏱ 45 min read 📊 Beginner 🗄️ SQL Course

SQL (Structured Query Language) is how we talk to databases. Whether you're a data analyst, backend developer, or just curious — SQL lets you ask questions about data and get instant answers. This lesson covers the four most fundamental building blocks: SELECT, WHERE, ORDER BY, and LIMIT.

1. What is a Database and a Table?

A database is an organized collection of data. Inside a database, data is stored in tables — think of a table like a spreadsheet, with rows and columns.

Let's imagine we have a table called employees:

idnamedepartmentsalarycity
1Priya SharmaEngineering85000Hyderabad
2Arjun ReddySales62000Bangalore
3Sneha KumarEngineering92000Hyderabad
4Vikram SinghMarketing58000Mumbai
5Anjali RaoSales71000Hyderabad

We'll use this table for every example in this lesson.

2. The SELECT Statement

The SELECT statement retrieves data from a table. The most basic form selects all columns using the * wildcard:

SQL
SELECT * FROM employees;

This returns every column and every row from the employees table. But usually you only need specific columns:

SQL
SELECT name, department, salary FROM employees;

This returns only the name, department, and salary columns for all 5 employees.

💡 Tip: Always select only the columns you need. Using SELECT * on large tables with many columns can slow down queries unnecessarily.

3. Filtering with WHERE

The WHERE clause filters rows based on a condition — only rows where the condition is true are returned.

SQL
SELECT name, salary FROM employees WHERE department = 'Engineering';

Result:

namesalary
Priya Sharma85000
Sneha Kumar92000

You can also use comparison operators with numbers:

SQL
SELECT name, salary FROM employees WHERE salary > 70000;

Common Comparison Operators

  • = — equal to
  • != or <> — not equal to
  • > — greater than
  • < — less than
  • >= — greater than or equal to
  • <= — less than or equal to
📌 Note: Text values in SQL must be wrapped in single quotes, like 'Engineering'. Numbers don't need quotes.

4. Sorting with ORDER BY

The ORDER BY clause sorts your results. By default it sorts in ascending order (A→Z, smallest→largest). Add DESC for descending order.

SQL
SELECT name, salary FROM employees ORDER BY salary DESC;

Result (highest salary first):

namesalary
Sneha Kumar92000
Priya Sharma85000
Anjali Rao71000
Arjun Reddy62000
Vikram Singh58000

You can also sort by multiple columns:

SQL
SELECT name, department, salary FROM employees ORDER BY department ASC, salary DESC;

This sorts by department alphabetically first, then within each department, by salary from highest to lowest.

5. Limiting Results with LIMIT

The LIMIT clause restricts the number of rows returned — useful for "top N" queries.

SQL
SELECT name, salary FROM employees ORDER BY salary DESC LIMIT 3;

This returns only the top 3 highest-paid employees.

⚠️ Common Mistake: The order of clauses matters! It must be SELECT ... FROM ... WHERE ... ORDER BY ... LIMIT. Writing them in a different order causes a syntax error.

6. Adding Comments

Comments help explain your SQL code and are ignored when the query runs:

SQL
-- This is a single-line comment SELECT name FROM employees; -- inline comment /* This is a multi-line comment */

✅ Summary

  • SELECT — choose which columns to retrieve
  • FROM — specify the table to query
  • WHERE — filter rows based on a condition
  • ORDER BY — sort results (ASC default, DESC for reverse)
  • LIMIT — restrict the number of returned rows
