❓ FAQ

Frequently Asked Questions

Everything you need to know about the KJSynthora HTML Viewer.

Can I edit HTML, CSS, and JavaScript separately? ▼
Yes. The editor has three separate tabs — HTML, CSS, and JavaScript. Each panel has its own editor. When you click Render, all three are combined into a single document and rendered in the preview panel, just like CodePen.
Is my code sent to a server or stored online? ▼
No. Everything runs 100% in your browser. Code is rendered using a sandboxed iframe — nothing is uploaded to any server. Your HTML, CSS, and JavaScript stay completely private on your device.
How do I test mobile responsiveness? ▼
Use the viewport buttons in the toolbar: 🖥 Desktop (full width), ⬛ Tablet (768px width), 📱 Mobile (390px width). The preview iframe resizes to simulate different screen sizes so you can check your CSS media queries and responsive layout.
Can I upload an existing HTML file? ▼
Yes. Click the "Upload HTML" button in the toolbar and select a .html or .htm file. The file contents will be loaded directly into the HTML editor. You can then render and edit it.
How does the console output work? ▼
The Console Output panel captures console.log(), console.warn(), console.error(), and JavaScript errors from code running in the preview iframe. This helps you debug your JavaScript without opening browser DevTools.
Can I use external libraries like Bootstrap or jQuery? ▼
Yes. Add a CDN link in your HTML editor's <head> section. For example, add Bootstrap's CDN link and it will load in the preview. The sandbox allows external script loading via CDN URLs.
What is Auto mode? ▼
Auto mode renders the preview automatically as you type, with a short delay (600ms). It's great for rapid visual feedback. Disable it if your page has slow-loading resources and you prefer to render manually.
