Frequently Asked Questions

What is an AI Cover Letter Generator?
An AI cover letter generator uses artificial intelligence to automatically create professional, personalized cover letters based on your information, target job, and preferred tone. It saves hours of writing while producing high-quality, ATS-friendly letters.
Do I need a Groq API key?
Yes, for AI-powered generation you need a free Groq API key from console.groq.com. No credit card required. The key is stored only in your browser — it never touches our servers.
What is an ATS-optimized cover letter?
ATS (Applicant Tracking System) is software companies use to filter applications. An ATS-optimized letter uses relevant keywords from the job description, proper formatting, and clear structure so it gets through automated screening before a human reads it.
Is my data private?
Yes. All form data stays in your browser. API calls go directly from your browser to Groq's API using your own key. We never store, log, or process your personal information on our servers.
Can I download the cover letter as PDF?
Yes! You can download your generated cover letter as a plain text (.txt) file or use the PDF option which opens your browser's print dialog for saving as PDF.
