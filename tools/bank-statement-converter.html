Frequently Asked Questions

Which Indian banks are fully supported? +
We support 50+ banks with pre-configured column profiles: SBI, HDFC, ICICI, Axis, Kotak, PNB, BOI, Bank of Baroda, Canara, Union Bank, UCO, IOB, Federal, Yes Bank, IDFC First, IndusInd, RBL, Bandhan, DCB, Karnataka Bank, South Indian Bank, J&K Bank, AU Small Finance, Equitas, Ujjivan, Paytm Payments Bank, Airtel Payments Bank, and 20+ more. For unlisted banks, Auto-Detect mode works with virtually any statement format.
Is my bank statement data secure? +
Yes, completely. All file parsing happens in your browser using JavaScript — PDF.js for PDFs and SheetJS for Excel/CSV. Your statement file never leaves your device and is never uploaded to any server. Once you close the browser tab, everything is cleared from memory. We recommend verifying this in your browser's Network tab (DevTools) — you'll see zero file upload requests.
How does PDF bank statement conversion work? +
The tool uses PDF.js to extract text content from your bank statement PDF page by page. It then applies smart pattern matching to identify transaction rows using date patterns (DD/MM/YYYY, DD-MM-YYYY, etc.) and amount patterns (numbers with decimal points). For scanned PDFs (image-based), the tool uses heuristic line detection to extract what it can — for best results with scanned statements, use a high-quality JPG or PNG scan instead.
What does Auto-Categorize do? +
Auto-Categorize reads each transaction description and matches it against 13 category keyword databases: Food & Dining (Swiggy, Zomato, etc.), Shopping (Amazon, Flipkart, etc.), UPI Transfer, ATM Withdrawal, Utilities & Bills, Travel & Transport, Entertainment, Healthcare, EMI & Loans, Salary & Income, Education, Investment, and Miscellaneous. The categories appear as color-coded badges in the table and are included in all exports. You can also edit categories inline when Inline Edit Mode is enabled.
What output formats are available? +
You can download in 6 formats: (1) Excel .xlsx with multiple sheets (Transactions, Summary, Categories, Monthly, UPI), (2) plain CSV for universal compatibility, (3) JSON for developers, (4) a formatted PDF summary report, (5) Monthly Excel with each month as a separate sheet, and (6) a filtered CSV that exports only your current filtered/searched view. All exports include category tags and cleaned descriptions.
Can I process multiple bank statement files at once? +
Yes — you can select multiple files when uploading and the tool will parse all of them and merge the transactions into one consolidated output. This is useful for combining 3 or 6 months of statements across one or multiple bank accounts. Duplicate transactions are automatically removed when the "Remove Duplicates" option is enabled.
What is UPI Deep Parsing? +
When enabled, UPI Deep Parsing extracts UPI IDs (e.g. merchant@upi, 9876543210@paytm) from transaction narrations, identifies the payment app used (Google Pay, PhonePe, Paytm, BHIM), and aggregates spend per UPI contact. This helps you see exactly who you're paying most via UPI and identify recurring vendors. The UPI Analysis tab gives a full breakdown with counts and amounts per UPI ID.
