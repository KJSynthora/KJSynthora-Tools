Frequently Asked Questions

Which Indian banks are fully supported? +
We support 50+ banks: SBI, HDFC, ICICI, Axis, Kotak, PNB, BOI, Bank of Baroda, Canara, Union Bank, UCO, IOB, Federal, Yes Bank, IDFC First, IndusInd, RBL, Bandhan, DCB, Karnataka Bank, South Indian Bank, J&K Bank, AU Small Finance, Equitas, Ujjivan, Paytm Payments Bank, Airtel Payments Bank, and 20+ international banks. Auto-Detect works for any unlisted bank.
Is my bank statement data secure? +
100% secure. All processing happens in your browser using PDF.js and SheetJS — your file never leaves your device. Verify yourself in browser DevTools Network tab — you'll see zero upload requests.
How does PDF bank statement conversion work? +
The tool uses PDF.js to extract text page by page, groups text items by Y-axis position to reconstruct lines, then applies date and amount pattern matching to identify transaction rows. For scanned PDFs, use high-resolution JPG or PNG for best results.
What does Auto-Categorize do? +
It reads each transaction description and matches against 13 keyword databases: Food & Dining, Shopping, UPI Transfer, ATM Withdrawal, Utilities, Travel, Entertainment, Healthcare, EMI, Salary, Education, Investment, Miscellaneous. Color-coded badges appear in the table and all exports.
What output formats are available? +
Six export formats: Excel .xlsx (multiple sheets), CSV, JSON for developers, PDF summary report, Monthly Excel (each month as separate sheet), and Filtered CSV (exports only your current view). All include categories and cleaned descriptions.
Can I process multiple bank statement files at once? +
Yes — select multiple files and all are parsed and merged into one output. Useful for combining 3–6 months or multiple accounts. Duplicate removal is automatic when enabled.
What is UPI Deep Parsing? +
Extracts UPI IDs (e.g. merchant@upi), identifies the payment app (Google Pay, PhonePe, Paytm, BHIM), and aggregates spend per contact. The UPI Analysis tab shows counts and amounts per ID with app breakdown.
Can I edit transactions before exporting? +
Yes — enable "Inline Edit Mode" toggle and all description and category cells become editable directly in the table. Your changes are included in all subsequent exports.
