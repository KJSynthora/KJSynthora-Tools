Frequently Asked Questions

What is a Cron Expression?

A cron expression is a string consisting of five or six fields that represents a set of times, normally used to schedule repetitive tasks on Unix-like operating systems.

AWS CloudWatch vs Standard Cron

AWS CloudWatch Events use a 6-field cron syntax (minutes, hours, day-of-month, month, day-of-week, year), whereas Linux crontab usually uses only 5 fields.
