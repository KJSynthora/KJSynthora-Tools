CropBox vs MediaBox — What's the Difference?

The MediaBox defines the full physical size of a PDF page. The CropBox defines the visible/printable region within that page. Most PDF viewers display the CropBox region. Setting the CropBox trims the visible area without removing the underlying content. Setting the MediaBox shrinks the page itself. For most use cases (removing scan borders, fitting content) setting the CropBox is sufficient.
