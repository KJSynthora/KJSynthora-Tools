Frequently Asked Questions

How do I create an Azure architecture diagram?

Click the Azure tab in the sidebar, drag services like App Service, Blob Storage, Azure SQL, or Azure Databricks onto the canvas, then connect them with the Connect tool. Use the "Azure Data Platform" or "Azure Web App" templates for a quick start.

Does this support Databricks Lakehouse diagrams?

Yes. The Databricks panel includes Delta Lake, Unity Catalog, MLflow, Auto Loader, Delta Live Tables, Bronze/Silver/Gold layers, Model Serving, and AI/BI Genie. Load the "Databricks Lakehouse" template for a full reference architecture.

Can I export my diagram as PNG or SVG?

Yes. Use File → Export PNG, Export SVG, or Export JSON. PNG is best for presentations, SVG for scalable vector graphics, and JSON to reload your diagram later.

Is this a free draw.io alternative?

Yes. KJSynthora Diagram Maker is completely free with no signup, no watermark, no file upload to servers. All processing is done locally in your browser.
