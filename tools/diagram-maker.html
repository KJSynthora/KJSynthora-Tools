📖 How to use this tool

1. Pick icons from the sidebar (AWS, Azure, GCP, Databricks, Shapes) and click or drag them to the canvas.
2. Press C (Connect tool) then click a source shape and a destination shape to draw an arrow.
3. Double-click any shape to rename it. Right-click for more options.
4. Use Templates in the menu for ready-made architecture starting points.
5. Use ✨ AI Generate to describe your diagram in English and auto-generate it.
6. Export as PNG, SVG or JSON from the File menu — completely free, no watermark.
